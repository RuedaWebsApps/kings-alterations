# Reglas del Proyecto - King's Alterations

1. **Stack Tecnológico:**
   - Mantener React 19 + Next.js 16 (App Router) + TypeScript + Tailwind CSS 4. No migrar a librerías externas innecesarias.
2. **Sin Formularios Tradicionales:**
   - No añadir formularios de contacto o presupuestos por correo. Las consultas comerciales deben dirigirse a WhatsApp `(512) 679-9240` o llamada directa.
3. **Identidad Visual Oficial:**
   - Utilizar exclusivamente la paleta azul pastel y dorada sobre fondo marfil.
   - El logotipo oficial `logo-king-alterations.png` (1000x670) debe preservarse sin distorsión ni alteración tipográfica artificial.
   - No emplear la estética rosa antigua del negocio anterior.
4. **Catálogo de Fotografías:**
   - Mantener las proporciones verticales de las prendas sin recortes agresivos.
   - Toda prenda del catálogo debe tener un ID único y categoría asignada en `src/data/catalog.ts`.
5. **Configuración para la Segunda Entrega:**
   - El video definitivo y el favicon final están programados para la entrega 2. Los slots están preparados y centralizados en `VideoSection.tsx` y `layout.tsx`.
