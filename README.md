# King's Alterations - Web & Catalog

Sitio web y catálogo visual premium para **King's Alterations** (Austin, TX), desarrollado con Next.js (App Router), React 19, TypeScript y Tailwind CSS.

## 🚀 Requisitos
- Node.js 18+ (recomendado 20 o 22+)
- npm o pnpm

## 📦 Instalación y Desarrollo Local
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo en http://localhost:3000
npm run dev

# Generar compilación optimizada de producción
npm run build

# Iniciar servidor de producción
npm run start
```

## 🌐 Despliegue en Vercel
1. Conectar el repositorio o importar la carpeta del proyecto a Vercel.
2. Preset detectado automáticamente: **Next.js**.
3. Build Command: `npm run build`
4. Output Directory: `.next`
5. Node.js Version: 20.x o superior.
